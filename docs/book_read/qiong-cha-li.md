# 《穷查理宝典》— 查理·芒格

> "我的生活中不断实践这样一个道理：准备、纪律、耐心、决断。"

## 基本信息

- **作者**：彼得·考夫曼 编（收录查理·芒格的演讲与智慧）
- **主角**：查理·芒格（Charlie Munger），巴菲特的合作伙伴
- **出版年代**：2005 年
- **地位**：商业与投资领域最具影响力的智慧合集之一

---

## 核心思想

### 多元思维模型 — 用不同学科的工具思考

> "手里拿着锤子的人，看什么都像钉子。"

不要只用一种思维方式看问题。从物理学、生物学、心理学、经济学、数学等多个学科借鉴思维工具，形成一个"格栅"来分析问题。

### 逆向思维 — 反过来想

> "如果我知道自己会死在哪里，我就永远不去那里。"

想知道如何成功？先想如何失败，然后避免。想获得幸福？先想什么会让你痛苦，然后远离。

### 能力圈 — 知道自己不知道什么

> "知道自己能力圈的边界，比圈子有多大更重要。"

专注于你真正理解的领域。在能力圈内做决策，对圈外的事保持谦逊和谨慎。

### 复利效应 — 耐心的力量

知识复利：每天学一点，几十年后你的认知将远超常人。不需要每次都做出惊人的决策，只需要持续做出合理的决策。

## 芒格的多元思维模型（精选）

| 学科 | 模型 | 应用 |
|------|------|------|
| 数学 | 复利效应 | 长期投资，知识积累 |
| 物理学 | 临界质量 | 努力达到质变的阈值 |
| 生物学 | 进化论 | 适应变化，自然选择 |
| 心理学 | 25 种认知偏差 | 避免决策错误 |
| 经济学 | 机会成本 | 做选择时考虑放弃了什么 |
| 工程学 | 冗余设计 | 为最坏情况留余地 |
| 统计学 | 均值回归 | 极端表现终将回归平均 |

## 25 种人类误判心理（精选）

| 偏差 | 说明 | 例子 |
|------|------|------|
| 激励偏差 | 人会为利益找到理由 | 房产中介总说"现在是好时机" |
| 社会认同 | 别人怎么做我就怎么做 | 从众购买热门股票 |
| 避免损失 | 失去的痛苦大于获得的快乐 | 不愿意卖出亏损的股票 |
| 一致性 | 一旦做出承诺就倾向维持 | 坚持错误的决策因为已经投入 |
| 锚定效应 | 被第一个接收到的信息左右 | 看到原价后觉得折扣价很便宜 |
| 可得性 | 容易想起的事觉得更重要 | 因为新闻报道而高估飞机失事概率 |

## 芒格的生活原则

1. **终身学习** — "每天睡觉前要比起床时更聪明一点"
2. **诚实正直** — 好名声是最好的资产
3. **耐心等待** — 不必频繁行动，等待击球区的好球
4. **独立思考** — 不跟风，不随大流
5. **简化复杂** — 用清单和简单规则做决策
6. **逆境是礼物** — 困难是学习和成长的机会

---

## 现代启示

1. **学习方法** — 跨学科阅读，建立自己的思维模型库
2. **投资决策** — 在能力圈内投资，有安全边际
3. **避免错误** — 认识认知偏差，用清单对抗
4. **长期主义** — 复利思维应用于知识、健康、关系
5. **做减法** — 少做蠢事比多做聪明事更重要
