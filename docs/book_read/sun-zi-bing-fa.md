# 《孙子兵法》— 孙武

> "知己知彼，百战不殆。"

## 基本信息

- **作者**：孙武，春秋末期军事家
- **成书年代**：约公元前 5 世纪
- **篇幅**：13 篇，约 6,000 字
- **地位**：世界公认的最伟大军事著作，被译为数十种语言

---

## 核心思想

### 不战而胜 — 最高战略

> "百战百胜，非善之善者也；不战而屈人之兵，善之善者也。"

最高明的胜利不是通过战斗获得，而是通过智慧、谋略和势态让对手不战而降。

### 知己知彼 — 信息为王

> "知己知彼，百战不殆；不知彼而知己，一胜一负；不知彼不知己，每战必殆。"

决策的质量取决于信息的完整性。了解自己和对手，才能做出正确判断。

### 势 — 创造有利态势

> "故善战者，求之于势，不责于人。"

高明的领导者不苛求个人英雄主义，而是创造一种大势，让普通人也能成功。

### 变 — 灵活应变

> "兵无常势，水无常形。"

没有永远适用的策略，要根据具体情况灵活调整，像水一样适应地形。

## 十三篇概览

| 篇名 | 核心要义 |
|------|----------|
| 始计 | 战前分析五要素：道、天、地、将、法 |
| 作战 | 速战速决，注重效率与成本 |
| 谋攻 | 以智取胜，不战而胜为上策 |
| 军形 | 先立不败之地，再求胜机 |
| 兵势 | 正面接敌，出奇制胜 |
| 虚实 | 避实击虚，集中优势兵力 |
| 军争 | 争夺主动权，以迂为直 |
| 九变 | 随机应变，不拘一格 |
| 行军 | 观察判断，洞察细节 |
| 地形 | 利用环境，因地制宜 |
| 九地 | 不同处境下的策略应对 |
| 火攻 | 借助外力，事半功倍 |
| 用间 | 情报工作的重要性 |

## 现代启示

1. **商业竞争** — "不战而胜"启发企业避免价格战，通过差异化取胜
2. **项目管理** — "多算胜少算"强调充分规划的重要性
3. **个人决策** — "知己知彼"提醒我们做决定前充分收集信息
4. **团队管理** — "求之于势，不责于人"是系统思维的体现
5. **创业策略** — "避实击虚"指导初创企业选择竞争薄弱的细分市场
