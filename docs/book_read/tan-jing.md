# 《坛经》— 惠能

> "菩提本无树，明镜亦非台。本来无一物，何处惹尘埃。"

## 基本信息

- **作者**：六祖惠能，弟子法海记录
- **成书年代**：约公元 7-8 世纪
- **篇幅**：约 12,000 字
- **地位**：中国佛教唯一被称为"经"的祖师著作，禅宗的根本经典

---

## 核心思想

### 顿悟 — 一念觉即佛

> "前念迷即凡夫，后念悟即佛。"

开悟不需要漫长的修行过程，只要在一念之间看清自性本来面目，当下就是觉悟。不是知识的积累，而是认知的翻转。

### 自性清净 — 本自具足

> "何期自性本自清净，何期自性本不生灭，何期自性本自具足。"

每个人的本心本来就是清净、完整、圆满的。不需要向外寻求，只需要去除覆盖在自性上的妄念。

### 无念无相无住

- **无念** — 不是不想，而是想而不执
- **无相** — 不是不见，而是见而不著
- **无住** — 不是不处，而是处而不留

### 定慧一体 — 非先后之分

> "定慧一体，不是二。"

禅定和智慧不是两件事，不是先定后慧。在日常生活中保持清醒觉知，就是定慧一体。

## 惠能 vs 神秀

| 维度 | 神秀（北宗） | 惠能（南宗） |
|------|-------------|-------------|
| 偈语 | 身是菩提树，心如明镜台。时时勤拂拭，勿使惹尘埃。 | 菩提本无树，明镜亦非台。本来无一物，何处惹尘埃。 |
| 修行观 | 渐修 — 逐步净化 | 顿悟 — 直见本性 |
| 起点 | 假设心已染污 | 自性本来清净 |
| 方法 | 持戒修行，循序渐进 | 识心见性，直截了当 |

## 经典公案与开示

| 公案 | 教义 |
|------|------|
| 风动幡动 | "不是风动，不是幡动，仁者心动" — 一切由心造 |
| 惠明求法 | "不思善，不思恶，正与么时那个是明上座本来面目" — 超越二元对立 |
| 不立文字 | 教外别传，不立文字，直指人心，见性成佛 |
| 担水砍柴（禅宗传统） | "饥来吃饭，困来即眠" — 日常即修行（此语更多出自后世禅师如大珠慧海） |

## 禅宗要义

```
不依赖经典 → 直接体验
不依赖仪式 → 当下觉知
不依赖他人 → 自性自度
不依赖时间 → 一念即悟
```

---

## 现代启示

1. **心理自由** — "本来无一物"帮助我们放下不必要的心理负担
2. **活在当下** — 禅宗强调此时此地的觉知
3. **去标签化** — 不被"我是什么人"的标签束缚
4. **简化生活** — 放下过多的追求和执着
5. **即时行动** — 顿悟思想鼓励当下改变，不等"准备好"
