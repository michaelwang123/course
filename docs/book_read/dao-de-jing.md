# 《道德经》— 老子

> "道可道，非常道；名可名，非常名。"

## 基本信息

- **作者**：老子（李耳），春秋时期
- **成书年代**：约公元前 6 世纪
- **篇幅**：五千余字，81 章
- **地位**：中国哲学最重要的经典之一，道家思想的奠基之作

---

## 核心思想

### 道 — 万物之源

道是宇宙的本原和规律，无形无象却生化万物。它不是具体的事物，而是一切事物背后的终极法则。

### 无为而治

"无为"不是什么都不做，而是不妄为、不强为。顺应自然规律行事，以最小的干预达到最大的效果。

### 柔弱胜刚强

> "天下莫柔弱于水，而攻坚强者莫之能胜。"

水看似最柔弱，却能穿石裂岩。真正的强大不在于刚硬，而在于柔韧与包容。

### 知足与谦下

> "知足不辱，知止不殆，可以长久。"

欲望无止境是痛苦的根源，知道满足、懂得适可而止才是长久之道。

## 经典章节精选

| 章 | 名句 | 智慧要点 |
|----|------|----------|
| 第1章 | 道可道，非常道 | 真正的道理超越语言 |
| 第8章 | 上善若水 | 最高的善像水一样利万物而不争 |
| 第33章 | 知人者智，自知者明 | 了解自己比了解别人更难更重要 |
| 第44章 | 知足不辱，知止不殆 | 知足知止是人生安全的保障 |
| 第76章 | 人之生也柔弱，其死也坚强 | 柔弱是生命力的标志 |
| 第81章 | 圣人之道，为而不争 | 做事但不争功 |

## 现代启示

1. **管理之道** — "无为而治"启发了现代管理中的授权与信任
2. **生活哲学** — 在快节奏时代，"知足""不争"提供了内心平静的路径
3. **领导力** — "功成事遂，百姓皆谓我自然"是最高境界的领导
4. **环保理念** — "人法地，地法天，天法道，道法自然"呼应了可持续发展
