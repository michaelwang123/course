# 《论语》— 孔子及弟子

> "学而时习之，不亦说乎？有朋自远方来，不亦乐乎？人不知而不愠，不亦君子乎？"

## 基本信息

- **作者**：孔子弟子及再传弟子编纂
- **成书年代**：约公元前 5 世纪
- **篇幅**：20 篇，约一万余字
- **地位**：儒家学说的核心经典，影响东亚文明两千余年

---

## 核心思想

### 仁 — 爱人之道

> "樊迟问仁。子曰：'爱人。'" — 颜渊篇

仁是孔子思想的核心，是人与人之间真诚的关爱。它不是抽象的概念，而是在日常生活中对他人的善意与责任。

### 礼 — 社会秩序

礼是人际交往的规范和社会运行的准则。不是僵化的形式，而是发自内心的尊重与恰当的行为方式。

### 学 — 终身成长

> "学而不思则罔，思而不学则殆。"

学习与思考相辅相成，知识与实践不可分离。孔子提倡终身学习、不耻下问。

### 君子 — 理想人格

> "君子坦荡荡，小人长戚戚。"

君子是孔子描绘的理想人格：有道德、有学问、有担当，内心坦然。

## 现代启示

1. **人际关系** — "己所不欲，勿施于人"是跨文化的道德金律
2. **教育理念** — "因材施教""不愤不启"启发了个性化教育
3. **职业发展** — "君子不器"提醒我们不要局限于某一技能
4. **自我修养** — "吾日三省吾身"是持续改进的方法论
5. **领导力** — "其身正，不令而行"强调以身作则
