# 投资入门

> "投资最大的风险是你不知道自己在做什么。" — 沃伦·巴菲特

## 投资的核心原则

### 1. 长期持有

- 时间是投资者最大的盟友
- 短期波动不可预测，长期趋势可以把握
- 频繁交易是亏钱的最快方式

### 2. 分散风险

- 不把鸡蛋放在一个篮子里
- 跨资产类别（股票、债券、现金）
- 跨地区（国内、国际）
- 跨时间（定投，不择时）

### 3. 低成本

- 管理费是确定的损失，收益是不确定的
- 指数基金费率 0.1-0.5% vs 主动基金 1-2%
- 长期来看，低费率基金跑赢大部分主动管理基金

### 4. 能力圈

- 只投你理解的东西
- 不理解的高收益 = 不可预测的高风险
- "不懂不投"不是胆小，是明智

## 新手最佳策略：指数基金定投

### 为什么是指数基金？

- 不需要选股能力
- 费率低（管理费 0.1-0.5%）
- 分散持有几百只股票，风险分散
- 长期跑赢 80% 的主动基金经理
- 巴菲特多次公开推荐给普通人

### 定投的威力

假设每月定投 3000 元，年化 10%：

| 年限　| 投入本金 | 最终金额 | 收益　　　|
| -------| ----------| ----------| -----------|
| 5 年　| 18 万　　| 23.2 万　| +5.2 万　 |
| 10 年 | 36 万　　| 61.5 万　| +25.5 万　|
| 20 年 | 72 万　　| 227.8 万 | +155.8 万 |
| 30 年 | 108 万　 | 678.1 万 | +570.1 万 |

### 定投操作指南

1. **选择标的** — 标普500指数基金（如 VOO、SPY）或全球股票指数基金
2. **设置自动扣款** — 每月工资日后第二天
3. **金额** — 月收入的 20-30%
4. **不看账户** — 不因短期涨跌改变计划
5. **持续 10 年以上** — 时间越长，亏钱概率越低

## 资产配置基础

### 简单版配置（适合大多数人）

```
年龄 < 35：股票类 80% + 债券类 20%
年龄 35-50：股票类 60% + 债券类 40%
年龄 > 50：股票类 40% + 债券类 60%
```

核心逻辑：年轻时能承受更高波动，年龄越大越应追求稳定。

### 永久组合（极简版）

| 资产　　　　 | 比例 | 作用　　　　　　|
| --------------| ------| -----------------|
| 股票指数基金 | 50%　| 增长引擎　　　　|
| 债券基金　　 | 30%　| 稳定器　　　　　|
| 现金/货基　　| 20%　| 流动性+抄底弹药 |

每年再平衡一次（涨多了的卖一些，跌多了的补一些）。

## 投资心理学：最大的敌人是自己

| 常见错误 | 心理原因　　 | 应对方式　　　　　　 |
| ----------| --------------| ----------------------|
| 追涨杀跌 | 从众心理　　 | 设定规则，严格执行　 |
| 频繁交易 | 行动偏差　　 | 减少看盘频率　　　　 |
| 亏了不卖 | 损失厌恶　　 | 设止损线　　　　　　 |
| 赚了急卖 | 害怕失去收益 | 设盈利目标，分批卖出 |
| All-in　 | 过度自信　　 | 永远留一部分现金　　 |
| 不敢入场 | 恐惧不确定　 | 小金额开始，积累信心 |

## 投资的时间线

:::tip[⏰ 记住这些]
- **1 年内：** 任何事都可能发生（大涨大跌都正常）
- **5 年：** 大概率正收益，但不保证
- **10 年：** 标普500历史上任何滚动10年均为正收益
- **20 年：** 复利效应开始显著
- **30 年：** 你会感谢当初的自己
:::
