# 收入增长策略

> "不要问'我怎么赚更多钱'，要问'我能为更多人解决更大的问题'。"

## 收入的本质公式

```
收入 = 解决问题的价值 × 影响人数 × 杠杆倍数
```

提升收入只有三条路：
1. **提高单位价值** — 解决更复杂的问题
2. **扩大影响范围** — 服务更多人
3. **增加杠杆** — 用资本、技术、团队放大效果

---

## 主动收入：提升职业价值

### 涨薪的底层逻辑

老板付你工资的原因只有一个：**你创造的价值 > 你的薪水**。

想涨薪：
- 承担更大的责任
- 解决更难的问题
- 变得更难替代
- 让决策者看到你的价值

### 职业杠杆点

| 杠杆 | 方式 | 收入天花板 |
|------|------|-----------|
| 时间换钱 | 普通打工 | 低（时间有限） |
| 技能换钱 | 高级专家/顾问 | 中高 |
| 管理杠杆 | 带团队 | 高 |
| 资本杠杆 | 投资/创业 | 无上限 |
| 媒体杠杆 | 内容/IP | 无上限 |
| 代码杠杆 | 产品/SaaS | 无上限 |

### 跳槽 vs 内部晋升

| 场景 | 选跳槽 | 选留下 |
|------|--------|--------|
| 薪资涨幅 | >30% 才值得动 | 内部机会更大 |
| 成长空间 | 当前公司已触顶 | 还有上升通道 |
| 行业趋势 | 当前行业在下行 | 行业前景好 |
| 人际资源 | 新平台人脉更有价值 | 当前人脉难以复制 |

## 副业：第二收入来源

### 好副业的标准

1. **利用你的优势** — 不是从零开始
2. **可积累** — 做得越久越有价值（vs 单次交易）
3. **可扩展** — 不完全靠时间换钱
4. **不影响主业** — 时间和精力可控

### 副业方向参考

| 类型 | 举例 | 特点 |
|------|------|------|
| 知识变现 | 写课程、做咨询、写书 | 前期投入大，后期边际成本低 |
| 技能服务 | 接外包、设计、翻译 | 直接变现，但时间换钱 |
| 内容创业 | 公众号、YouTube、播客 | 慢启动，但有复利效应 |
| 电商/代理 | 带货、代理分销 | 门槛低，竞争大 |
| 产品开发 | SaaS工具、App、模板 | 技术门槛高，天花板高 |

## 被动收入：让钱为你工作

### 常见被动收入来源

| 来源 | 前期投入 | 维护成本 | 收益预期 |
|------|----------|----------|----------|
| 指数基金定投 | 本金 | 极低 | 年化 8-12% |
| 房产出租 | 大量资金 | 中等 | 年化 3-5% |
| 课程/电子书 | 大量时间 | 低 | 因内容而异 |
| 股息/分红 | 本金 | 极低 | 年化 3-6% |
| 自动化生意 | 资金+精力 | 视业务而定 | 变数大 |

### 被动收入的真相

:::note[💡 没有"真正"的被动收入]
所有被动收入都需要：
- **前期的大量主动投入**（学习、创作、攒本金）
- **定期的维护和优化**
- **对风险的持续关注**

"睡后收入"是结果，不是起点。先把主动收入做到位，再逐步构建被动收入。
:::

## 收入增长路径建议

**20s：**
- 投资自己 > 投资市场（学一项高价值技能的回报远超任何投资）
- 尝试副业但不急于赚钱——积累认知和经验

**30s：**
- 主业收入应达到一定水平
- 开始系统性构建被动收入
- 副业找到方向并持续投入

**40s：**
- 被动收入应能覆盖基本生活
- 有选择"不工作"的底气
- 收入来源多元化（不依赖单一来源）
