# 财务认知与理财

## 不是教你暴富，而是建立钱的底层认知

大多数人对钱的理解停留在"赚更多、花更少"。但真正的财务智慧是一套系统——关于如何赚、如何存、如何投、如何花、如何保护。

理解钱的规律，不是为了成为富翁，而是为了让钱成为你实现人生目标的工具，而非束缚你的枷锁。

## 财务自由路线图

```
第一步：生存安全 → 6 个月紧急备用金
第二步：债务清零 → 消除高息负债
第三步：保障到位 → 重疾+意外+定期寿险
第四步：持续投资 → 收入的 20-30% 定投
第五步：被动收入 > 支出 → 财务自由
```
