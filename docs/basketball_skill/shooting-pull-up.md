# 急停跳投（Pull-up Jump Shot）

## 概述

急停跳投是将行进间的动能瞬间转化为垂直起跳的投篮技术。它是中距离得分的核心武器，也是区分普通射手和精英得分手的关键技术。Chris Paul、DeMar DeRozan、Kevin Durant 都是急停跳投的大师。

与定点投篮不同，急停跳投需要解决一个核心矛盾：**如何在高速移动中保持出手的稳定性和准确性**。

---

## 技术原理

### 动能转化

行进间的水平速度需要在急停时转化：
- 一部分被制动（脚与地面的摩擦）
- 一部分转化为垂直起跳力（能量上传）
- 如果制动不彻底 → 飘投，方向控制差

**急停越干脆，投篮越稳定。**

---

## 两种急停方式

### 跳步急停（Jump Stop）

- **动作**：行进中双脚同时跳起、同时落地
- **优点**：任何一只脚都可以作为轴心脚，出手选择多
- **适用**：正面突破急停、接球急停
- **要点**：
  - 落地时双脚与肩同宽
  - 膝盖弯曲缓冲，重心迅速降低
  - 落地瞬间球已在投篮位置（Set Point）

### 一二步急停（Stride Stop / 1-2 Stop）

- **动作**：先落第一只脚（刹车脚）→ 再落第二只脚
- **优点**：制动更强，适合高速状态
- **适用**：全速运球急停、从侧翼切入
- **要点**：
  - 第一步脚跟先着地，身体重心后坐制动
  - 第二步调整站位宽度和方向
  - 第一只落地的脚 = 轴心脚（不可再移动）

---

## 技术分解

### 1. 运球节奏

- 急停前最后一次运球要**大力**，球弹回手中时正好是急停收球的瞬间
- 如果运球和急停节奏脱节 → 出现"先停后拿球"的尴尬，给防守反应时间

### 2. 收球时机

- 在最后一步蹬地的**同时**双手收球
- 球直接举到 Set Point，不要在腰间停留
- "地板到手到出手"一气呵成

### 3. 起跳

- 利用急停时膝盖弯曲的弹性势能直接向上弹起
- 不需要额外下蹲蓄力（浪费时间）
- 起跳方向：**垂直向上**，不是向前跳

### 4. 空中出手

- 在最高点附近出手
- 保持与定点投篮一致的手型和出手动作
- 核心收紧保持空中平衡

### 5. 落地

- 落在起跳位置或略前方（不超过 30cm）
- 双脚同时着地，膝盖弹性缓冲
- 如果落地偏移太多 → 说明急停不彻底

## 训练进阶

### Level 1：无球急停

- 全速跑 → 跳步急停 → 三威胁姿态
- 全速跑 → 一二步急停 → 面筐
- **目标**：急停后身体零晃动，1 秒内稳定
- **每种 10 次**

### Level 2：运球急停定点

- 半速运球 → 急停 → 跳投（无防守）
- 从罚球线区域开始，不急于拉远
- **要点**：收球-举球-出手的时间差尽量短
- **每组 15 球，3 组**

### Level 3：变速急停

- 慢运球 → 突然加速 2 步 → 急停跳投
- 训练重点：变速后的重心控制
- **方向变化**：向左突 → 急停 / 向右突 → 急停
- **每侧 10 球**

### Level 4：运球组合 + 急停

- 体前变向 → 加速一步 → 急停跳投
- 胯下运球 → 推进 → 急停跳投
- 犹豫步（Hesitation）→ 加速 → 急停跳投
- **模拟实战：** 每次动作假设有防守人存在
- **每种组合 8 球**

### Level 5：对抗急停

- 搭档跟防，轻度身体接触
- 训练在对抗下保持出手节奏
- **每组 10 球**

## 常见错误与纠正

| 错误 | 表现 | 纠正 |
|------|------|------|
| 急停不干脆 | 飘在空中，方向偏 | 增强大腿离心力量（深蹲、减速训练） |
| 收球太晚 | 停住了球还在运 | 最后一拍运球大力，同步收球 |
| 球从腰间举起 | 出手慢，被封盖 | 收球即到 Set Point，跳过"腰间中转站" |
| 向前跳而非向上 | 飘投，短球 | 急停时后脚跟先着地制动水平速度 |
| 急停后重新下蹲 | 节奏慢，给防守回位时间 | 利用急停弯曲的膝盖直接向上弹 |

## 实战应用

### 高效出手位置

急停跳投的最佳区域是**肘区（Elbow）和罚球线两侧**：
- 距离适中，下肢力量足够支持
- 防守人难以判断突破还是投篮
- 传球线路丰富，投不了还能分球

### 典型比赛情境

1. **挡拆后绕掩护** → 急停跳投
2. **快攻中遇到回防** → 急停收球跳投
3. **持球面框 1v1** → 变向 → 急停中距离
4. **时间紧迫** → 不执着三分，急停中距离更稳

---

## 体能基础

急停跳投对下肢**离心力量**（减速能力）要求很高。推荐辅助训练：

| 训练 | 作用 | 建议 |
|------|------|------|
| 后脚抬高蹲（保加利亚蹲） | 单腿制动力量 | 每侧 8×3 组 |
| 箱跳（Box Jump）下落稳定 | 落地控制 | 5×3 组，强调落地零晃动 |
| 减速跑（Deceleration Drill） | 高速制动能力 | 冲刺 10 米 → 3 步停住 |

:::tip[🎯 关键心得]
急停跳投的"准"不在手上，在脚上。脚步稳了，上半身自然稳。练急停跳投的本质是练"刹车"。
:::
