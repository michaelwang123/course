# 亲密关系与社交

## 关系的质量，决定了生命的质量

哈佛大学持续 85 年的幸福研究得出了一个简单的结论：**决定人一生幸福和健康的最大因素，不是财富、名望或智商，而是关系的质量。**

但关系不是"有了就行"——它需要能力、意识和持续的投入。这个板块帮助你系统性地提升关系能力。

## 关系能力的核心

```
好的关系 = 安全感 + 连接感 + 成长感

安全感：我可以在你面前做真实的自己
连接感：我们之间有深层的理解和共鸣
成长感：这段关系让我们各自变得更好
```

## 自检：你的关系能力

| 能力 | 1-5分 | 表现 |
|------|-------|------|
| 倾听 | ? | 能否全神贯注地听，不急着给建议？ |
| 表达 | ? | 能否清晰地说出自己的感受和需求？ |
| 边界 | ? | 能否在不伤害关系的前提下说"不"？ |
| 修复 | ? | 冲突后能否主动修复，而非冷战？ |
| 脆弱 | ? | 能否在亲近的人面前展示不完美？ |

如果总分低于 15 分，这个板块的内容会对你特别有帮助。
